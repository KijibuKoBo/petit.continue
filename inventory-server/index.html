ダッシュボード

木地完成で木地在庫、塗装済で完成在庫に。完成在庫が安全在庫を下回るとアラート表示。

在庫アラート

直近の生産予定

完成予定が近い順（出荷済を除く）

生産予定

予定 → 木地完成 → 塗装済 → 出荷済。状態を進めると在庫へ自動反映されます。

出荷

状態を「出荷済」にしたロットの一覧です。出荷は生産予定で状態を進めて登録します。

在庫・製品マスタ

木地在庫＝木地完成の数量。完成在庫＝塗装済の数量。予測在庫＝木地＋完成＋予定。製品名をクリックでロット別の明細を表示します。

ユーザー管理

編集権限・閲覧権限を設定できます。閲覧権限は参照のみ可能です。

変更履歴

誰が・いつ・何を変更したかの記録です（新しい順・最新300件）。

データ管理

データはエックスサーバー上のデータベースに保存され、全端末で共有されます。

バックアップ / 復元

サーバー保存に加え、定期的にJSONを書き出して保管しておくと安心です。読み込むと製品・生産予定・出荷先がファイルの内容で置き換わります（ユーザー情報は対象外）。

初期化

実行にはパスワードが必要です。元に戻せません。
