ダッシュボード

木地完成で木地在庫、塗装済で在庫に。在庫が安全在庫を下回るとアラート表示。

在庫アラート

直近の生産予定

完成予定が近い順（出荷済を除く）

生産予定

未着手（予定）の生産だけを一覧します。「木地完成」を押すと木地在庫へ移ります。

出荷

状態を「出荷済」にしたロットの一覧です。出荷は生産予定で状態を進めて登録します。

在庫・製品マスタ

木地在庫＝木地完成の数量。在庫＝塗装済の数量（出荷可能）。製品名をクリックでロット別の明細を表示します。

分析

既に入力されているロット・出荷・破損の記録から自動集計します。追加の入力は要りません。

ユーザー管理

編集権限・閲覧権限を設定できます。閲覧権限は参照のみ可能です。

変更履歴

誰が・いつ・何を変更したかの記録です（新しい順・最新300件）。

データ管理

データはエックスサーバー上のデータベースに保存され、全端末で共有されます。

バックアップ / 復元

サーバー保存に加え、定期的にJSONを書き出して保管しておくと安心です。
JSONを書き出し：製品・ロット・破損・塗装指示・出荷先・ユーザー（パスワード含む）を完全バックアップ。別サーバーへの引越しにそのまま使えます。
JSONを取り込み：現在ログイン中のサーバーで、製品・ロット・破損・塗装指示・出荷先をファイル内容に置換します（既存のユーザーはそのまま）。
引越し先での復元：新サーバーでまだユーザーがいないとき、ログイン画面の「バックアップから復元」リンクから取り込めば、元のメール・パスワードでログインできます。

CSVで書き出し

Excelでそのまま開けます（文字化けしません）。分析タブの各表も、表ごとにCSVボタンから書き出せます。

初期化

実行にはパスワードが必要です。元に戻せません。
